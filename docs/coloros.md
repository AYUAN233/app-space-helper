# ColorOS / OPPO 风险拦截说明

> 这是本项目在 ColorOS 设备上最重要的一项系统设置。

## 症状

如果「应用空间助手」只处理了一个应用就停止，或者悬浮控制层突然消失、系统无障碍里本应用被自动关闭，通常不是应用崩溃，而是被 ColorOS 的「风险行为拦截」判定为：

> 异常操控设备

无障碍服务被系统拦截后，控制层的进程和无障碍绑定会一起中止，看起来就像应用自己退出了。

## 处理

在 ColorOS / OPPO / OnePlus / realme 的「手机管家」中：

1. 打开 **手机管家**。
2. 进入 **风险行为拦截**。
3. 保持「拦截时提醒」开启，便于以后发现问题。
4. 查看拦截记录，找到 **应用空间助手 · 异常操控设备**。
5. 把「应用空间助手」加入白名单 / 允许名单。
6. 回到系统 **设置 → 无障碍**，重新开启「应用空间助手 · 自动关闭」。
7. 重新打开应用运行。

不同 ColorOS 版本中，入口也可能叫：

- 手机管家 → 安全防护 → 风险行为拦截
- 手机管家 → 风险应用管理
- 设置 → 安全 → 风险行为拦截

如果找不到，可以在系统设置或手机管家里搜索「风险行为拦截」。

## 建议同时做

- 应用信息 → 耗电管理 → **允许后台运行**
- 应用信息 → **允许自启动**
- 最近任务里锁定「应用空间助手」卡片
- 系统电池设置中关闭 **睡眠待机优化** 或省电模式
- 允许通知，以显示运行中的保活通知

## 注意

- 系统更新、手机管家更新、卸载重装后，检查白名单是否还在。
- 如果仍然中断，先查看手机管家的拦截记录，确认是否重新出现「异常操控设备」。
- 这不是 Root/破解；系统安全模块仍然有权阻止无障碍自动化。
